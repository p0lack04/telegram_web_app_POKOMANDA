# Telegram Mini App

- Проверь актуальную версию SDK и официальные API, используемые проектом; не выдумывай методы.
- Инициализируй приложение через `ready()`, корректно обрабатывай `expand()`, viewport, theme params, safe areas, back button и MainButton по назначению.
- Работай с Telegram WebApp API через адаптер/хук, чтобы приложение запускалось и вне Telegram в dev-режиме.
- `initDataUnsafe` допустим для отображения предварительных данных, но не для установления доверенной личности.
- Отправляй raw `initData` на backend. Backend валидирует HMAC-подпись официальным алгоритмом, `auth_date` и допустимый TTL; секрет бота существует только на сервере.
- Не принимай telegram user ID из query/body как доказательство авторизации.
- Не генерируй JWT на клиенте и не используй фальшивые токены.
- Защити повторное использование/просроченные данные согласно модели сессий.
- Обеспечь безопасный fallback при открытии в обычном браузере; dev auth должна быть отключена в production.
- Тестируй back navigation, закрытие/возврат, viewport resize, dark theme и мобильную клавиатуру.
- Haptics — только для значимых действий, с graceful fallback.
