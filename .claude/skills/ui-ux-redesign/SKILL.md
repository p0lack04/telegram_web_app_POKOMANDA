# UI/UX redesign

- Сначала перечисли реальные пользовательские роли и ключевые задачи каждой роли.
- Составь карту навигации; сократи глубину, не прячь важные действия.
- Mobile-first: ширина 320–430 px как базовый сценарий, затем планшет/desktop.
- Учитывай Telegram viewport, safe-area insets, тему Telegram и системный контраст.
- Применяй дизайн-токены: цветовые роли, spacing, radius, elevation, типографика.
- Не делай всё карточками; используй список/таблицу только там, где это ускоряет работу.
- Touch targets ориентиром не меньше 44 px; формы имеют label, hint, validation и понятные ошибки.
- Для длинных списков добавляй поиск, фильтры, сортировку и пустые состояния.
- Каждая загрузка/мутация имеет loading, success и error feedback; не допускай двойной отправки.
- Поддерживай light/dark и `prefers-reduced-motion`.
- Статусы обозначай текстом и цветом/иконкой, не только цветом.
- Не перегружай главную; показывай персональный контекст и следующий полезный шаг.
- Не меняй доменную терминологию без согласования.
- Проверь keyboard/focus, screen reader labels, контраст и масштабирование текста.
- Добавь визуальные regression/e2e проверки ключевых экранов, если стек позволяет.
